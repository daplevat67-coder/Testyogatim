# ПУЛЬС v1.0 — мини-тренировки для Android

Самостоятельное офлайн-приложение с короткими тренировками и бережной мотивацией.

- 5 отжиманий, 8 приседаний и планка 15 секунд (цели настраиваются).
- Пять вариантов настроения, уровень усталости и заметки.
- Облегчённый режим, обычный режим или отдых.
- Таймер, история и статистика за 7 дней.
- Данные остаются на устройстве. Нет аккаунта, рекламы и сетевых разрешений.

Android-приложение построено на Kotlin и системном WebView с полностью встроенным интерфейсом. Приложение не требует Интернета.

## Сборка

На странице **Actions** открой запуск **Build PULSE Android APK** и скачай артефакт **PULSE-v1.0-debug-apk**. Внутри находится **PULSE-v1.0-debug.apk**.

Сборка локально (Android SDK 35, JDK 17):
```bash
cd pulse/android
gradle :app:assembleDebug
```

APK для тестирования (debug), не для Google Play. Это отдельный проект в каталоге `pulse/`, существующий сайт в корне репозитория не меняется.

При боли или чрезмерной усталости тренировку следует остановить. Самооценка настроения не является медицинской диагностикой.
