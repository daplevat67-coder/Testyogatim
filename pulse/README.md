# ПУЛЬС v1.1.1 — мини-тренировки по зонам тела

Приложение для Android с короткими тренировками, выбором уровня и наглядной схемой тела.

## Возможности

- Выбор уровня: **Новичок**, **База**, **Заряжен**.
- Выбор мышц: **всё тело**, **руки/бицепс**, **грудь**, **пресс**, **ноги**, **спина**.
- Иллюстрация человека с подсветкой нужных групп мышц и короткие инструкции по каждому упражнению.
- Отслеживание настроения и усталости, облегчённый режим и отдых.
- Таймер, история и прогресс за неделю.
- Локальные данные без сервера и регистрации.

## APK

В **GitHub Actions → Build PULSE Android APK** выберите успешную сборку и скачайте артефакт `PULSE-v1.1.1-debug-apk`. В архиве лежит `PULSE-v1.1.1-debug.apk`.

**Важно:** не используйте вручную перепакованный v1.1 APK. Эта сборка подписана штатным Android Gradle Plugin с APK Signature Scheme v2/v3, совместимым с Android 15. Workflow проверяет подписи через `apksigner verify --verbose`.

Это debug-сборка. Ключ отладки может отличаться от прошлой сборки, поэтому для установки новой версии поверх прежней может потребоваться удаление прежнего приложения. **Перед удалением экспортируйте историю (Настройки → Сохранить мою историю), если она нужна; простая повторная установка не восстанавливает её автоматически.**

## Сборка локально

Android SDK 35, JDK 17, Gradle 8.11.1:
```bash
cd pulse/android
gradle :app:assembleDebug
```

Приложение использует Kotlin WebView с локальным интерфейсом, без разрешения на доступ к сети.

При боли, головокружении или сильной усталости тренировку следует остановить. Самооценка настроения не является медицинской диагностикой.
