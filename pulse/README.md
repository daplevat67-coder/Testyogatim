# ПУЛЬС v1.2 — автоматический счётчик упражнений

Офлайн Android-приложение для коротких тренировок с настроением, усталостью, выбором уровня, зон мышц и изображением тела.

## Новое — счёт упражнений камерой

- **Приседания**, **отжимания (разные варианты)** и **сгибания на бицепс**: теперь доступны кнопки **«📷 Считать»**.
- При первом запуске пользователь разрешает камеру. Поставьте телефон устойчиво так, чтобы суставы были в кадре.
- На экране видно изображение с камеры, распознанные суставы (скелет), число повторов и подсказка для следующего движения.
- Счёт обновляется после полного цикла «прямые суставы → сгибание → выпрямление» и сглаживается от случайных колебаний.
- **Назад** не сохраняет результат; **Готово** возвращает счёт в основной план. Если цель не достигнута, можно продолжить с накопленного значения.
- Есть кнопка паузы и переключение передней/задней камеры.
- Работа локальная через ML Kit (bundled pose model) и CameraX, нет сетевых разрешений, фото и видео не сохраняются.

Счётчик — **бета**, зависит от освещения, ракурса и видимости суставов, может ошибаться. Остальные упражнения пока отмечаются вручную, автоматическое определение техники или медицинская оценка не заявляются.

## Сборка APK

GitHub → Actions → Build PULSE Android APK → успешный запуск → Artifacts → **PULSE-v1.2.0-debug-apk**. В ZIP лежит APK.

GitHub Actions собирает APK через Android Gradle Plugin и проверяет v2/v3 подпись с `apksigner verify`. Перед удалением старой версии экспортируйте историю: debug-подпись в разных workflow может отличаться, и Android не позволит обновить приложение поверх старого APK.

## Совместимость и осторожность

Android 8.0+; камера и возможность предоставления разрешения нужны для автосчёта. Рекомендуется Android 10+ для производительности. Если не видно суставов, в основном плане можно отметить вручную.

При боли или головокружении остановите упражнение. Особенно избегайте нагрузки через боль в суставах; не оценивайте здоровье по цифрам счётчика.
